# THE KING — LeBron James Fan Tribute

An unofficial, single-page editorial fan tribute to LeBron James: four titles, four MVPs, 40,000+ points, told through a scroll-driven, kinetic-typography experience. Built with Next.js (App Router), React 19, Tailwind CSS v4, Framer Motion, and shadcn/ui primitives.

Reference: the initial brief/design direction was sourced from `cr7-fan-page-rho.vercel.app`; the hero and eras sections were deliberately redesigned to diverge from it, other sections still loosely mirror its structure.

## Stack

- **Framework**: Next.js 16 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS v4, `class-variance-authority`, `tailwind-merge`
- **Motion**: Framer Motion — scroll-linked transforms, mask reveals, reduced-motion aware
- **UI primitives**: Radix UI (`separator`, `slot`, `tabs`) wrapped as shadcn-style components in `components/ui/`
- **Icons**: lucide-react
- **Audio**: Web Audio API only — no audio assets, opt-in and off by default

## Content & data

All copy and stats live in **`lib/lebron-data.ts`** — never hardcode facts in components. Ground rules baked into that file:

- Headline honours (titles, MVPs, Finals MVPs, golds, all-time scoring rank) are exact, documented facts.
- Point/game totals are **rounded approximations** of regular-season figures, labelled `approx` in the UI.
- The radar chart in `stat-explorer.tsx` is an *editorial* index (subjective 0–100 read) and is clearly labelled as interpretation, not official data.
- Bump `STATS_AS_OF` whenever the numbers are refreshed.

## Motion & accessibility

- All animation goes through `lib/motion.ts` shared variants/easings — don't hand-roll new easing curves in components.
- Every motion-heavy component respects `prefers-reduced-motion` (via `useReducedMotion` / `use-reduced-motion.ts`); reduced-motion users get equivalent content without the scroll-jacking/parallax.
- Custom cursor and sound are both opt-in/desktop-gated and degrade gracefully.
- A skip-to-content link is present in `app/layout.tsx`.

## Deployment

Deploys to Vercel. `robots: { index: false, follow: false }` is set in `app/layout.tsx` — this is intentionally not indexed as an unofficial fan tribute; remove that if the indexing policy changes.
